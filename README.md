# Vajra

Vajra is an experimental operating system designed around
isolated computation, capability-based security, message-oriented
communication, adaptive scheduling, and distributed computation.

## Initial Target

- Architecture: x86-64
- Development Host: Windows 11
- Emulator: QEMU
- Compiler: LLVM/Clang
- Assembler: NASM
- Build System: CMake

## Development Philosophy

Vajra is being developed incrementally.

Each subsystem should be understood, implemented, compiled,
booted, tested, and debugged before the next layer is added.
